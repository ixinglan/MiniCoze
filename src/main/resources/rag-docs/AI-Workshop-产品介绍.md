# AI Workshop 产品介绍

AI Workshop 是一个本地运行的「综合知识库 + 自主任务 Agent 工作台」，目标是帮助开发者通过"做产品"的方式学习 Spring AI Alibaba。

## 核心定位

它相当于一个迷你版的 Coze 或 Manus，所有能力都围绕"让大语言模型真正能干活"展开，而不是只会聊天。

## 功能模块

1. 综合知识库：支持把团队的产品文档、制度文档、技术 FAQ 导入系统，基于 RAG（检索增强生成）让模型基于这些私有资料回答问题，而不是凭空编造。
2. 多轮对话记忆：助手能记住上下文，历史记录在 MySQL 中持久化，刷新页面不丢失，并支持多会话管理。
3. 结构化输出：把自然语言需求解析成规整的工单对象（标题、分类、优先级、截止时间等），可直接落库或对接外部系统。
4. Agent 工作台：未来将支持把多个工具编排起来，自动完成复杂任务。

## 技术栈

- JDK 17 + Spring Boot 3.5
- Spring AI 1.1.2 + Spring AI Alibaba 1.1.2.2
- 对话模型使用 DeepSeek V4（通过 OpenAI 兼容协议接入）
- 向量化使用本地 Ollama 的 bge-m3 模型，免费且无需云密钥
- 记忆持久化使用 MySQL（库名 mini_coze）

## 适用人群

已经具备 Spring Boot 基础、想系统掌握 Spring AI Alibaba 的 Java 开发者。

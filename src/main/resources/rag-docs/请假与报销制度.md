# 请假与报销制度

本文档说明公司内部的请假流程与报销标准，供员工查阅。

## 年假规定

- 正式员工每年享有 10 天带薪年假。
- 入职满一年后，年假按当月剩余月份比例折算发放。
- 年假可以累计，但最多结转 5 天到次年。

## 请假流程

1. 提前在 OA 系统提交请假申请，注明请假类型、起止时间与事由。
2. 请假 1 天以内由直属主管审批；3 天以内由部门负责人审批；超过 3 天需分管副总审批。
3. 病假需提供医院出具的诊断证明，否则按事假处理。
4. 紧急请假可先口头报备，事后 3 个工作日内补提交申请。

## 报销标准

- 市内交通报销上限为每天 50 元，需提供发票。
- 出差住宿标准：一线城市每晚不超过 400 元，其他城市不超过 300 元。
- 餐饮补贴为每天 100 元，无需发票，按出差天数发放。
- 所有报销需在费用发生后 30 天内提交，逾期不予办理。

## 注意事项

报销单必须真实合规，弄虚作假一经发现按严重违纪处理。

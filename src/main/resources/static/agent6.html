🕸️ 阶段 6 · Agent 编排

从“一个能调工具的 Agent”升级到“多个 Agent 协作 + 图编排”。五种形态：单 Agent 工具循环、顺序、路由、手写意图路由图、手写监督者多智能体。 主力模型：DeepSeek V4（若 Supervisor 嵌套调用不稳，可切 qwen）。

ReactAgent · 单 Agent 工具循环

一个 Agent 自己决定调哪些工具、调几次，直到任务完成（底层在 Agent 和 Tool 之间循环）。

SequentialAgent · 顺序编排

子 Agent 按顺序串执行：前一个的输出自动喂给后一个（写作 → 评审）。

LlmRoutingAgent · 路由分发

LLM 判断问题类型后，单次分发给最合适的研究 / 编程 / 写作助手（不循环）。

graph-core 手写 · 意图路由工作流

用 StateGraph 手写最小图：分类节点 → 条件边 → 对应 worker。理解"图编排"原理的入门示例。

graph-core 手写 · Supervisor 多智能体

监督者节点循环决定调用研究员 / 程序员，直到判定 FINISH。演示"多智能体协作"本质就是一张图。
